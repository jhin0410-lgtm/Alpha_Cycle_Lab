# Backtest Assumptions

- 입력 날짜는 거래소 현지 거래일을 나타내는 날짜값이며, 거래 세션은 `Asia/Seoul` 기준의 시간대 있는 세션으로 정의됩니다.
- 신호일과 체결일은 분리됩니다. 기본 `next_open` 실행은 신호 세션의 다음 실제 거래 세션에 주문을 생성합니다.
- `same_close`를 명시적으로 선택한 경우에만 신호 세션의 장 종료 가격을 주문 기준가격으로 사용합니다.
- 재무·거시 데이터는 `available_date <= evaluation_date`인 행만 평가일 스냅샷에 포함됩니다.
- `first_release`는 자연키별 최초 공개 revision을 사용하고 이후 수정치를 소급 반영하지 않습니다.
- `latest_known`은 평가일까지 공개된 revision 중 가장 최근 값을 사용하며 미래 수정치는 포함하지 않습니다.
- `revision_sequence`가 증가할수록 `available_date`가 과거로 역행할 수 없습니다.
- `retrieved_at`은 `available_date`보다 빠를 수 없으며 UTC timestamp로 정규화합니다.
- 공시·경제지표의 실제 장중 공개 순서와 공급자별 정의 차이는 원천 데이터가 보증해야 합니다.
- 현재 재무·거시 어댑터는 로컬 CSV/DataFrame만 지원하고 외부 API를 호출하지 않습니다.
- 지원 주문 유형은 market과 limit, 유효기간은 DAY와 GTC입니다.
- DAY 주문은 한 일봉에서 한 번의 체결 기회를 사용한 뒤 남은 수량이 만료됩니다.
- GTC 주문은 pending 또는 partially_filled 상태로 다음 데이터 세션에 이월됩니다.
- 주문 하나는 여러 Fill을 만들 수 있고 각 Fill에는 결정론적 고유 `fill_id`가 부여됩니다.
- `max_volume_participation`은 종목별 일일 volume에 적용되며 같은 종목의 여러 주문이 한도를 공유합니다.
- 지정가 도달 여부는 매수의 경우 daily low, 매도의 경우 daily high로 판정합니다. 실제 장중 체결 순서는 재현하지 않습니다.
- 지정가 체결 timestamp는 정확한 장중 시각을 추정하지 않고 세션 close를 사용합니다.
- `is_halted=true`인 행에서는 체결이 발생하지 않습니다. DAY 잔량은 만료되고 GTC 잔량은 이월됩니다.
- 가격 충격은 고정 금액과 basis-point 슬리피지의 합으로 단순화합니다.
- 휴장일과 주말은 명시적 캘린더가 제공되었을 때만 비거래일로 처리되며, 데이터에 비거래일 날짜가 포함되면 오류를 발생시킵니다.
- 공식 KRX 휴장일 공급자와 조기폐장, 특별 거래 세션은 이 버전에서 지원하지 않습니다.
- 실행가격과 포트폴리오 평가는 `raw` 가격만 사용합니다. `adjusted_close`는 `close`를 자동 대체하지 않습니다.
- split-adjusted 가격은 분석용이며 분할 이벤트와 동시에 회계에 반영하면 이중 조정이 됩니다.
- total-return-adjusted 가격은 미래 배당 정보가 과거 가격에 소급 반영될 수 있으므로 실행 및 시가평가에 사용하지 않습니다.
- split과 reverse split은 해당 effective session의 주문 처리 전에 적용합니다.
- 분할은 현금, 실현손익, 총 원가를 바꾸지 않습니다. fractional share가 생기면 현금 정산을 추정하지 않고 오류를 냅니다.
- cash dividend, stock dividend, delisting은 아직 회계 정책이 없으므로 발견 시 백테스트를 중단합니다.
- 시점별 유니버스가 제공되면 `member_from <= session < member_to`인 종목 중 해당 시점에 공개된 이력만 전략에 전달합니다.
- 편출 종목의 기존 포지션은 자동 삭제하거나 강제매도하지 않습니다.
- 시점별 유니버스가 없으면 survivorship bias가 남을 수 있습니다.
- 수수료와 세금은 각 부분체결 금액에 개별 적용합니다. 제공 설정값은 요율 예시일 뿐입니다.
- 공매도와 레버리지는 금지하고 정수 주식만 사용합니다.
- 유동성 한도는 이번 세션에 제안된 부분체결 수량과 해당 일봉의 `trading_value`를 기준으로 검사합니다.
- 성과지표 기본 연환산 일수는 252, 무위험수익률은 0이며 설정할 수 있습니다.
- 거래 없음, 0 분모, 표본 부족 지표는 0으로 안전하게 반환합니다.
