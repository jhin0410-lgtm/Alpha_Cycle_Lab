# Backtest Assumptions

- 입력 날짜는 거래소 현지 거래일을 나타내는 시간대 없는 ISO 날짜입니다.
- 종가로 생성된 신호는 기본적으로 다음 데이터 행의 시가에 체결됩니다.
- 일봉 한 개당 종목별 체결 기회는 하나이며 부분체결과 주문 잔량은 없습니다.
- 가격 충격은 고정 금액과 basis-point 슬리피지의 합으로 단순화합니다.
- 수수료와 세금은 체결금액에 적용합니다. 제공 설정값은 요율 예시일 뿐입니다.
- 공매도와 레버리지는 금지하고 정수 주식만 사용합니다.
- 유동성 한도는 해당 일봉의 `trading_value` 대비 주문 참조금액으로 검사합니다.
- 성과지표 기본 연환산 일수는 252, 무위험수익률은 0이며 설정할 수 있습니다.
- 거래 없음, 0 분모, 표본 부족 지표는 0으로 안전하게 반환합니다.
- 기업행동, 상장폐지, 종목 편입 이력 미포함 시 survivorship bias가 발생할 수 있습니다.
