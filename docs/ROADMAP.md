## Current direction

ACL is an **AI-native Point-in-Time Investment Research Operating System**.

The immediate product path is:

```text
#310 / PR #311 Forecast Tournament + 3/6/12M Opportunity Set — merged foundation
→ #312 / PR #313 canonical Product Charter / Master Roadmap / Architecture / Knowledge Pack Standard
→ R1-A Observable universe and change engine
→ R1-B Research planner and adaptive research-model runtime
→ R1-C Deep research transmission integration
→ R1-D Counter-thesis and blind-spot loop
→ R1-E Decision memory and outcome learning
→ R1-F End-to-end and cold-start acceptance
→ Product Release R1 complete when the twelve-capability closed-loop acceptance contract passes

Coverage Release C1 — fifteen major industry families through operational/calibrating Knowledge Packs — is a separate coverage track. It may progress in parallel once the R1 research-model contract is stable and is not a prerequisite for R1 functional completion.

Later product releases are defined in `ACL_MASTER_ROADMAP.md`, including R2 and R3. Do not recreate the obsolete `Phase 1 → ACL v1 → opportunity discovery later` sequence.
```

Check `ACL_MASTER_ROADMAP.md` and live GitHub state for the exact current milestone before execution.
